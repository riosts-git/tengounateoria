> *«Lo quiero, pero creo que no puedo conseguirlo».*

- **Variables:** valencia positiva + proyección negativa (inhibición motora).
- **Cómo se siente:** falta de impulso, frustración, renuncia.
- **Familia de palabras:** desgano, desaliento, frustración, impotencia, resignación.

**Qué hace el cuerpo:** sigue orientado hacia lo que desea, pero se contrae. La energía baja, el impulso no alcanza para empezar. Queremos, pero no nos movemos.

**Para qué sirve:** para no gastar energía donde creemos que no podemos ganar. También para apaciguar: bajar la excitación, frenar, descansar.

**A favor:** abre una pausa para discernir. No todo lo que queremos merece nuestra energía, y la desmotivación nos permite soltar metas que ya no valen la pena. No es tristeza: podemos no estar tristes y aun así no tener ganas de nada.

**En contra:** cuando se generaliza, ya no soltamos una meta: soltamos todas. Ahí aparecen la apatía, la abulia, la indiferencia general.
